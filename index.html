BEFORE YOU START

Who is V8 Agent OS for?+

Independent developers, creators and small teams who want to use AI for real projects. Start with a clear research, development or creative task and build your own way of working from there.

Does it replace my computer's operating system?+

V8 is a desktop AI workspace running on Windows, macOS or Linux. Install and configure the app to get started. You do not need to replace your existing operating system.

Does local first mean completely offline?+

Your computer is the center of your project work. When you use cloud models, search or creative services, relevant data is sent to the services you configure. Network use and data flows depend on those capabilities. Not every task can run offline.

What do I need, and what does it cost?+

You need a supported computer, a project folder and a working model connection. V8 source code is MIT licensed. Model APIs and third-party services are billed by their providers; the open-source software does not include free model credits. The quick start walks through initial setup.

Can the phone run desktop tasks on its own?+

Phone is a paired remote interface. Your desktop needs to stay running and reachable. You can follow tasks, add materials and respond to decisions; the phone does not replace the desktop runtime.

What stage is the product at?+

Desktop and Android Phone previews are available, with capabilities and installation experience still evolving. Concept illustrations on this page explain ways of working. The product film will appear here when available. See GitHub Releases for current platform assets and updates.
